🎯 How Windowed-Random Admission Works

This system groups users into 3-second cohorts based on when they join. Within each cohort, admission order is randomized (eliminating network/timing advantages). Across different cohorts, earlier groups are always prioritized (respecting wait time). The admission controller releases 5 users per second to prevent inventory service overload.
